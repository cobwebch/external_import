Import configuration examples
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

The :ref:`External Import Tutorial <cobweb/externalimport_tut:start>` provides
a detailed introduction into External Import configuration, but it cannot cover
everything, especially the most complex possibilities. Some are used in the
the test extension: https://github.com/fsuter/externalimport_test. This chapter
explains in detail some of these configurations.

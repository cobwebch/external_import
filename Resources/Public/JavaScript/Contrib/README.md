# How to update datatables

Go to datatables.net > Download and select the following options:

- for the styling framework: Bootstrap 5
- for the packages: DataTables only (jQuery is not needed since DataTables 3)
- no extensions

Download the minified version and replace the file in this folder.

The same file can also be fetched directly from the DataTables CDN,
replacing the version number as needed:

https://cdn.datatables.net/v/bs5/dt-3.1.5/datatables.min.js
